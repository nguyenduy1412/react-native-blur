# Search assets

The library's canonical site is `https://nguyenduy1412.github.io/react-native-blur/`. `docs/robots.txt`, `docs/sitemap.xml`, and `docs/llms.txt` are generated by `npm run docs` and already live with GitHub Pages.

`https://kaizer-app.vercel.app` is the author portfolio. It must not use the library name as its page title, and its canonical URL must stay on itself. These files in `seo/` are the portfolio copies:

| File | Public URL | Purpose |
| --- | --- | --- |
| `robots.txt` | `https://kaizer-app.vercel.app/robots.txt` | Lets search and AI crawlers read the portfolio. |
| `sitemap.xml` | `https://kaizer-app.vercel.app/sitemap.xml` | Lists only the portfolio homepage. |
| `llms.txt` | `https://kaizer-app.vercel.app/llms.txt` | Points AI tools at the canonical docs site. |

Copy them into the portfolio site's `public/` directory. Do not add a second canonical, title, or `SoftwareSourceCode` block for `@nguyenduy1412/react-native-blur` on that homepage.
